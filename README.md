# AI Innovation Portfolio — Kartika Dirangga

Portofolio berbasis Vite + React + Tailwind.

## Jalankan lokal
```
npm install
npm run dev
```

## Foto profil
Taruh foto di `public/foto-profil.jpg` (rasio 4:3 paling pas, di bawah 500 KB).
Untuk mengganti foto lewat browser, buka situs dengan `?admin=1`.

## Deploy
Push ke GitHub, lalu import repo di vercel.com. Framework terdeteksi otomatis (Vite).
